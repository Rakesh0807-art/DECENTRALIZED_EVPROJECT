# EVChargeChain Major Project — Added Features

## Modules

1. EV request and charging planner
2. OpenStreetMap charging-station visualization
3. Road route calculation and MCS route animation
4. Multi-EV / multi-station / multi-MCS simulation
5. Congestion and queue simulation
6. MCS assignment using distance, cost and energy/status constraints
7. Traffic blockchain with signed transaction and verifier threshold
8. Trust-score security mechanism
9. Security Attack Lab
10. Cooperation points and station leaderboard
11. Contribution and reward distribution
12. Shapley-value standalone calculation
13. Research experiment runner
14. Baseline-vs-proposed comparison view
15. CSV experiment export

## Research caution

The multi-EV simulation, queue occupancy, MCS movement and research experiment values are prototype/synthetic simulations. Map locations are geographic context. Do not claim real-time charging availability, live vehicle telemetry, or measured field performance unless a real data provider or field dataset is connected.

For a research paper, record parameter values, random seeds, number of runs, dataset provenance, baselines and statistical summaries.
